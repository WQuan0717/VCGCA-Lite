# VCGCA-Lite v1.0.5

本次更新修复手势控制、设置管理和摄像头服务中的问题，并提供经过构建后检查的 Windows x64 安装包与便携版。

## 下载与使用

- `VCGCA-Lite-Setup-v1.0.5.exe`：Windows 安装包，可安装或更新已有版本。
- `VCGCA-Lite-v1.0.5-windows-x64.zip`：便携版，解压完整目录后运行 `VCGCA-Lite.exe`。
- `SHA256SUMS.txt`：上述文件的 SHA-256 校验值。

安装包和便携版均包含 Python 运行时、依赖和手势识别模型。需要 Windows 10/11 x64 或支持 x64 应用的兼容系统，以及允许桌面应用访问的摄像头。

## 修复内容

- 手势组合绑定开始准备的手，避免双手之间串用响应手势；正确处理单只手丢失和检测顺序变化。
- 响应前检查目标丢失超时，使用单调时钟并保证识别输入时间戳递增。
- 删除全部手势映射后保持禁用；设置默认值与当前值独立；恢复默认覆盖全部相关选项；配置写入失败保留原文件。
- 摄像头失败、停止与重启均释放资源并重置会话；Windows 优先 DirectShow，打开失败时回退默认后端。
- 修复提前打开调试窗口后的预览、无效映射提示、静音 HUD 名称和源码开机启动命令。
- 支持设置快捷方式；统一应用、EXE 和安装器版本；修正安装器的运行中检测与项目链接。
- 修复 Conda 打包遗漏原生 DLL 和宿主 PATH 同名库冲突，验证程序可独立于开发环境启动。

## 开发与验证

提供 Python 3.11 Conda 环境定义、固定依赖与完整依赖锁定文件。
30 项回归测试覆盖设置、手势状态、摄像头生命周期与 Windows 集成；另对内置模型、窗口初始化和真实摄像头启停进行了检查。
最终 EXE 在移除 Conda 路径的环境中通过窗口、模型推理及两轮摄像头启停检查，确认使用随包运行时。
打包程序可使用 `--check-environment --report result.json` 执行隔离检查，追加 `--camera` 可验证摄像头。

手势识别效果受光线、摄像头及手部遮挡影响，可通过托盘菜单的“显示调试窗口”查看识别结果。
