# VCGCA-Lite

一个基于 Python + PyQt6 开发的系统工具应用框架。

## 版本信息

- **当前版本**: v0.1.0
- **开发阶段**: 框架搭建阶段
- **最后更新**: 2026-04-19

## 功能特性

### 已实现功能

#### 🎨 用户界面
- **启动动画** - 美观的启动画面，带进度条动画
- **系统托盘** - 静默运行，右键菜单操作
- **设置窗口** - 多标签页设置界面
- **HUD悬浮窗** - 可自定义的悬浮显示窗口
- **调试窗口** - OpenCV实时视频显示

#### ⚙️ 设置系统
- 设置持久化保存
- 实时生效（无需重启）
- 修改检测与状态联动
- 恢复默认功能

#### 🔧 技术特性
- 单文件EXE构建
- 版本自动管理
- 配置文件存储在用户目录

## 快速开始

### 环境要求
- Python 3.10+
- Windows 操作系统

### 安装依赖
```bash
pip install -r requirements.txt
```

### 运行程序
```bash
python main.py
```

### 构建EXE
```bash
python build_exe.py
```

构建后的EXE文件位于 `dist/VCGCA-Lite-v0.1.0.exe`

## 项目结构

```
VCGCA-Lite/
├── main.py                 # 程序入口
├── build_exe.py           # EXE构建脚本
├── requirements.txt       # 依赖列表
├── src/
│   ├── tray_app.py       # 托盘应用主类
│   ├── windows/          # 窗口模块
│   └── utils/            # 工具模块
├── dist/                 # 构建输出目录
└── docs/                 # 文档目录
```

## 使用说明

### 基本操作
1. 运行程序后，图标会出现在系统托盘
2. 右键托盘图标打开菜单
3. 选择相应功能进行操作

### 设置说明
- **常规**: 开机启动、启动动画
- **显示**: HUD透明度、尺寸、位置
- **高级**: 调试模式、日志记录
- **关于**: 版本信息
